This directory contains skills grouped by purpose. Start by identifying the category that matches your goal, then choose a skill from that folder.

- **`instruction`**: Skills that explicitly define how an agent should behave. They set expectations for things like workflow, decision-making, and response style.
- **`knowledge`**: Skills that provide agents with relevant knowledge and context. The added context may influence an agent's responses, but shaping the response is not their primary purpose. They are meant to make conversations with users smoother and help agents work with the right background information.
- **`macro`**: Snippet-based skills for users who want to perform a specific task. They replace instructions that users would otherwise have to type repeatedly.
- **`template`**: Skills for generating documents or other output in a specific format. They define structure and required elements in advance, making results more consistent.
